# Olist E-Commerce Analytics: Incremental ETL Pipeline + Power BI Dashboard

## 📌 Project Overview

This project is an end-to-end e-commerce analytics solution built using the **Olist Brazilian E-Commerce dataset**.  
It covers the complete analytics workflow from raw CSV data to business-ready Power BI dashboards.

The project includes:

- Python-based data cleaning
- Star schema data modeling
- Incremental load pipeline
- Local CSV-based Power BI output layer
- Power BI semantic model
- DAX measures
- Four interactive business dashboards

The goal of this project is to demonstrate practical skills in **Data Engineering, Business Intelligence, Power BI, DAX, Data Modeling, and Dashboard Storytelling.

---

## 🎯 Business Problem

E-commerce businesses need to monitor revenue, order volume, product performance, customer geography, delivery performance, payment behavior, and customer satisfaction.

This project solves that problem by creating a structured analytics solution that helps business users answer questions such as:

- What is the total revenue and order volume?
- Which products and categories generate the most sales?
- Which states and cities contribute most to revenue?
- How are deliveries performing?
- What percentage of deliveries are late?
- Which payment methods are most used?
- How are customers reviewing their orders?
- Which areas need business or operational improvement?
